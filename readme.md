## description 
This C program is designed to analyze employee salaries while also recording student details for identification. It allows the user to enter salaries of up to 10 employees and provides a menu to display all salaries, total and average salary, highest and lowest salary, count of employees above or below the average, and sorted salaries. The program uses loops, conditionals, and a simple bubble sort algorithm to perform these operations, displaying the student’s name, registration number, and section in every output.
